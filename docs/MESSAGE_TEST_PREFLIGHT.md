# 메시지 검증 — 가동 전 점검 (2026-08-18)

> 정본은 `docs/CUSTOMER_VALIDATION_OPERATIONS.md`. 이 문서는 **켜기 직전에
> 무엇이 준비됐고 무엇이 안 됐는지**만 기록한다.

## 왜 지금 이걸 했나

리드가 **1명**이고 10일간 신규가 **0건**이다. 그동안 모의투찰 알고리즘을
다듬었는데, 사정률 오차의 하한은 제도가 정해서(§MOCK_BIDDING_DESIGN §9)
더 짜낼 것도 없다. 병목은 제품이 아니라 **유입**이고, 그걸 가장 값싸게 재는
장치가 이미 만들어져 있었다 — 다만 **켜져 있지 않았다.**

## 실동작 검증 결과 ✅

구현 349줄에 테스트가 **0건**이었다. "배포·외부 모집 전 검수 중"이라면서
검수 장치가 없던 셈이다. `tests/test_message_validation.py` **24건**을 채웠다.

문서가 약속한 안전장치가 실제로 거는지 **껐다 켜서** 확인했다:

| 안전장치 | 무력화했을 때 |
|---|---|
| 이미지 4값 검증(경로 prefix·traversal·캡션 필수어) → 503 | **6건 실패** |
| 비치헤드 밖 참가자 차단 | **4건 실패** |
| 서버 경과 시간 가드(브라우저 `exposure_ms` 위조 방어) | **1건 실패** |

항진명제가 아니다. 그 외 확인분: 미가동 시 404 · 잘못된 키 403 · 한 참가자
한 메시지 고정 · 코호트 내 A/B 균형(10명 → 5:5) · 다른 코호트 토큰 거부 ·
중복 제출 멱등 · 자동 코딩(4코드 적중, 낙찰가 예측 오해 탐지) ·
**표본 10 미만은 어떤 경우도 게이트 통과 불가** · 오해 2건이면 차단.

## 화면 — 교체 완료 ✅

처음 후보였던 `guide-assets/01-main-g2b-with-sidepanel.png` 는 **쓸 수 없었다.**
담긴 공고가 **물품 구매**(실험실습기자재 서버 구매, `R26BK01543466-000`)인데
문서 요건은 "타깃에 맞는 실제 공개 **전기공사** 공고"다. 게다가 물품 공고를
띄운 채 계산기 계약 종류를 **공사**로 고른 성립 불가 조합이고, 물품은
포지션에서 제외 대상이다(`CLAUDE.md`: "물품은 하한선 없어 안전게임 아님").
비치헤드에게 5초 보여주면 **"우리 얘기가 아니네"**로 읽힌다.

새로 캡처해 교체했다 — `guide-assets/06-electrical-notice-with-sidepanel.png`

| | |
|---|---|
| 공고 | 영천공설시장 안전관리패키지 지원사업 전기공사 |
| 공고번호 | `R26BK01672263-000` · 경상북도 영천시 |

**마스킹**: 브라우저 크롬(주소창·북마크바·프로필)을 통째로 잘랐다 — 거기에
회사명·타사 인트라넷·계정 아이콘이 전부 있었다. 파란 헤더 시작점(y=160)을
색으로 스캔해 자르고 1280폭으로 맞췄다(1280×624, 198KB). 남은 것은 나라장터
공개 정보와 BidEasy 패널뿐이며 패널은 **비회원** 상태다.

`_configured_test_image()` 실호출로 **경로·캡션 검증 통과 확인**.

⚠️ **알아둘 것**: 이 화면에는 "A값이 자동 추출되지 않았어요" 경고가 떠 있다.
정직한 실제 화면이지만, 5초 노출에서 **제품이 잘 안 되는 인상**을 줄 수 있다.

**이 화면으로 진행하기로 했다**(2026-08-18 결정). A값을 입력한 화면이 낫다는
것은 **추정이지 검증된 사실이 아니고**, 이 테스트가 재려는 것이 정확히 그
"메시지가 어떻게 읽히는가"이기 때문이다. 첫 10명의 자유서술에서 **A값·자동
추출을 부정적으로 언급하는지** 보고, 나오면 그때 교체한다.

⛔ 이미지를 합성하거나 숫자를 끼워 넣지 않는다 — 실제 공개 화면이어야 한다.

## 남은 것 — 사람이 해야 하는 하나

**모집 채널.** 문서가 "운영진 승인을 받은 커뮤니티와 기존 수신 동의
관계에만"으로 못 박아 뒀다. 공개 사업자 명단 전용 금지.

## 켜는 절차 (채널 승인 뒤)

```bash
# 1) 접근 키 생성 — 채널마다 다른 키(서버가 해시로 코호트를 가른다)
python -c "import secrets; print(secrets.token_urlsafe(32))"

# 2) 서버 .env.production 에 4줄 (⛔ Git·문서·스크린샷에 남기지 않는다)
MESSAGE_TEST_ACCESS_KEYS=<키1>,<키2>
MESSAGE_TEST_IMAGE_PATH=/guide-assets/06-electrical-notice-with-sidepanel.png
MESSAGE_TEST_IMAGE_CAPTION=공개 G2B 화면 · 공고번호 R26BK01672263-000 · 2026-08-18 기준
MESSAGE_TEST_ENABLED=true          # ← 반드시 마지막

# 3) 배포 후 확인: 키 없이 403, 잘못된 캡션이면 503 이어야 한다
```

캡션에는 **출처(`공개 G2B` 또는 `나라장터`) · `공고번호` · `기준`** 이 모두
들어가야 한다 — 하나라도 빠지면 서버가 503으로 막는다(테스트가 강제).

**모집이 끝나면 해당 키를 설정에서 제거한다.**

## 판정 (사전등록, 사후 변경 금지)

표본 **10명 이상** · 4코드 중 3개 이해 **70%+** · 신뢰도 중앙값 **4+** ·
낙찰가 예측 오해 **2건 미만**. 10명으로 통계적 승자를 선언하지 않는다.
