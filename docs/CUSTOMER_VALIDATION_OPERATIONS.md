# 고객 검증 운영표·인터뷰 가이드

> 상태: 실행 준비 — 외부 연락 전 대상·문안 승인 필요
> 기간: 최초 연락일로부터 14일
> 목표: 실제 공사 입찰 담당자 20명 접촉, 인터뷰 5건, 유효 고객 리드 1명 이상
> 정본 실험 설계: `docs/AD_CAMPAIGN_VALIDATION.md`

## 1. 운영 원칙

- 같은 모집원에서 조건이 비슷한 대상 20명을 선정한다.
- 대상자를 확보한 순서대로 아래 사전 배정표에 넣는다. 반응을 본 뒤 그룹을 바꾸지 않는다.
- 한 업체에는 한 가지 메시지만 보낸다. 안전/자격 메시지를 중복 발송하지 않는다.
- 공개된 대표번호·대표 이메일·공식 문의 채널만 사용한다. 불필요한 개인정보는 기록하지 않는다.
- 최초 연락과 3영업일 뒤 후속 연락 1회까지만 허용한다. 거절·수신 중단 요청은 즉시 반영한다.
- 인터뷰 녹음은 사전 동의를 받은 경우에만 한다. 문서에는 이름 대신 참가자 ID를 쓴다.
- 제품을 설명하기 전에 최근 실제 공고와 현재 업무 방식을 먼저 묻는다.

## 2. 대상자 선정 기준

### 포함 우선순위

1. 전기공사 또는 전문건설 업체
2. 대표나 실무자가 나라장터 공사에 직접 참여
3. 최근 3개월 안에 실제 투찰 경험이 있음
4. 월 10건 이상 검토하거나 반복적으로 공고를 찾음
5. 실제 공고 한 건을 화면으로 함께 볼 수 있음

### 제외 기준

- 입찰대행·광고대행·교육업체
- 아파트·대학교·국방 등 현재 제품 범위 밖의 입찰만 수행하는 업체
- 직접 투찰 경험이 없는 일반 정보 탐색자
- 테스트 계정, 내부 관계자, 제품 개발 참여자
- 연락 수신을 원하지 않는다고 밝힌 업체

## 5. 15분 인터뷰 질문지

### 시작 — 1분

1. 오늘은 판매보다 현재 입찰 업무를 이해하기 위한 대화라고 설명한다.
2. 메모 또는 녹음 여부를 확인하고, 원하지 않으면 기록하지 않는다.
3. 가능하면 최근 검토했던 실제 공고 한 건을 열어달라고 요청한다.

### 현재 행동 — 5분

1. 최근 공사 공고를 하나 골랐을 때 처음부터 투찰 직전까지 어떤 순서로 확인했나요?
2. 참여하지 않기로 한 최근 공고가 있다면, 어느 조건에서 중단했나요?
3. 금액과 하한선을 확인할 때 어떤 사이트·엑셀·메모를 사용하나요?
4. 업종·지역·실적·적격심사 조건은 누가, 어디에서 확인하나요?
5. 최근 다시 확인하거나 계산을 고쳐야 했던 사례를 보여줄 수 있나요?

### 문제의 강도 — 3분

6. 이 과정에서 시간이 가장 많이 드는 단계는 무엇인가요?
7. 잘못 판단했을 때 생기는 가장 큰 손해는 무엇인가요?
8. 현재 방식이 불편해도 계속 쓰는 이유는 무엇인가요?

### 제품 관찰 — 4분

9. 설명 없이 배정된 링크를 열고 실제 공고 기준으로 계산 또는 진단을 완료해 주세요.
10. 처음 멈추거나 되돌아간 지점은 어디인가요?
11. 결과 중 믿기 어렵거나 추가 근거가 필요한 부분은 무엇인가요?
12. 다음 공고에서도 다시 쓸 상황이 있다면 어떤 상황인가요?

### 종료 — 2분

13. 이 문제를 해결하기 위해 현재 비용을 내거나 별도 도구를 사용하고 있나요?
14. 일주일 뒤 실제 공고 한 건으로 다시 확인해 봐도 괜찮을까요?
15. 같은 일을 직접 하는 다른 담당자 한 명을 소개해 줄 수 있나요?

## 7. 판정 규칙

- **유효 고객 리드**: 목표 업종의 실제 입찰 담당자이며 연락처 확인과 후속 연락 동의가 완료됨.
- **활성 사용자**: 계산 또는 진단을 완료하고 프로필 완성이나 첫 안전 판정까지 수행함.
- **반복 문제**: 인터뷰 3건 이상에서 설명을 유도하지 않았는데 같은 업무 문제가 나옴.
- **계속**: 유효 고객 리드 1명 이상 또는 반복 문제 1개가 확인됨.
- **제품 흐름 개선**: 링크는 열지만 계산·진단 완료 전에 같은 지점에서 2명 이상 이탈함.
- **대상 재설계**: 20명 접촉과 인터뷰 5건 뒤에도 목표 고객 적합성과 반복 문제가 확인되지 않음.

클릭과 긍정적인 말만으로 성공을 판정하지 않는다. 실제 공고 사용, 완료 행동, 후속 연락 동의를
우선한다.
