# 고객 검증 연락 문안·UTM 정본

> 상태: 발송 전 승인 필요
> 대상: `docs/CUSTOMER_VALIDATION_OPERATIONS.md`에서 `연락승인` 상태인 참가자만
> 원칙: 한 업체 한 메시지, 3영업일 뒤 후속 1회, 거절 시 즉시 종료

## 1. 통제할 조건

- 안전/자격 메시지는 문제 설명과 랜딩만 다르게 한다.
- 발신자, 발송 요일·시간대, 문장 길이, 15분 요청, 판매 목적이 아니라는 설명은 같게 유지한다.
- 평일 10:00~11:30 또는 14:00~17:00에 하루 최대 5건씩 보낸다.
- 링크에는 이름·전화번호·업체명 같은 개인정보를 넣지 않는다.
- 두 그룹의 반응을 확인하기 전 문안을 고치지 않는다. 명백한 오류만 수정하고 변경 시각을 기록한다.

## 5. 전화 첫 문장

안녕하세요. 공사 입찰 업무용 도구를 만드는 BidEasy입니다. 판매 전화는 아니고, 실제 입찰
담당자분이 공고를 확인하는 방식을 배우기 위해 15분 인터뷰를 요청드리고 있습니다. 지금 간단히
말씀드려도 괜찮을까요?

허락을 받은 뒤 참가자 그룹에 해당하는 문제만 설명한다. 상대방이 원하지 않으면 감사 인사를 하고
통화를 종료하며 다시 연락하지 않는다.

## 6. UTM 규칙

| 모집 경로 | `utm_source` | `utm_medium` | `utm_campaign` |
|---|---|---|---|
| 대표 직접 소개 — 안전 | `founder_intro` | `referral` | `validation_202608_safety` |
| 대표 직접 소개 — 자격 | `founder_intro` | `referral` | `validation_202608_filter` |
| 허가된 커뮤니티 — 안전 | 실제 채널명 | `community` | `validation_202608_safety` |
| 허가된 커뮤니티 — 자격 | 실제 채널명 | `community` | `validation_202608_filter` |
| 네이버 광고 — 안전 원안 | `naver` | `cpc` | `validation_202608_safety` |
| 네이버 광고 — 자격 원안 | `naver` | `cpc` | `validation_202608_filter` |

`utm_content`는 DB 판정에 사용하지 않는다. `users.signup_campaign`과 `leads.utm_campaign`에 남는
`utm_campaign` 접미사로 그룹을 판별한다. 참가자 ID나 개인정보는 URL에 넣지 않고 운영표에서만
연결한다.

## 7. 발송 전 체크리스트

- [ ] 대상자가 운영표에서 `연락승인` 상태다.
- [ ] 그룹과 링크의 `utm_campaign` 접미사가 일치한다.
- [ ] 발신자와 회신 가능한 연락처가 명확하다.
- [ ] 같은 업체에 다른 그룹 메시지를 보낸 적이 없다.
- [ ] 하루 발송량이 5건을 넘지 않는다.
- [ ] 수신 거절·제외 대상이 아니다.
- [ ] 발송 직후 날짜와 채널을 운영표에 기록했다.
- [ ] 후속 연락은 최초 연락 3영업일 뒤 1회만 예약했다.
