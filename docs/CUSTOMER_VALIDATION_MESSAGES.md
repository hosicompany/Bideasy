# 허가형 온라인 모집 문안·링크 규칙

> 상태: 외부 게시·발송 전 운영자 승인 필요
> 대상: 운영진이 게시를 허용한 커뮤니티 또는 이미 관련 정보 수신에 동의한 관계만
> 금지: 전화 모집, 공개 사업자 명단 콜드 이메일·문자, 무단 반복 게시

## 1. 공통 모집 문안

서버가 메시지를 무작위 배정하므로 모집 문안은 A/B에 공통으로 쓴다.

```text
전기·전문공사 입찰을 직접 담당하시는 분께 짧은 온라인 테스트를 부탁드립니다.

나라장터 공고 화면에서 쓰는 도구의 첫 문장이 제대로 이해되는지 확인하는 테스트입니다.
화면을 5초 본 뒤 세 문항에 답하며, 전화나 영업 연락은 없습니다. 전기·전문공사 1~10인 업체에서
월 10건 이상 공고를 직접 검토하는 분을 대상으로 합니다.

참여 링크: <승인된 채널별 링크>

BidEasy는 조달청·나라장터의 공식 또는 제휴 서비스가 아닌 민간 서비스입니다.
```

보상을 제공할 때만 다음 문장을 사실에 맞게 덧붙인다.

```text
조건에 맞고 응답을 완료한 분께 테스트 참여 보상을 제공합니다. 설치·가입·후기 작성은 보상 조건이
아닙니다.
```

## 2. 동의 관계 1회 안내

기존에 BidEasy 관련 테스트 안내 수신에 동의한 사람에게만 다음처럼 보낸다.

```text
안녕하세요. 동의해 주신 BidEasy 온라인 제품 테스트가 열려 안내드립니다.
약 2분 동안 화면을 보고 자유롭게 답하는 비대면 테스트이며 전화 일정은 없습니다.

참여: <승인된 채널별 링크>

이번 안내를 원하지 않으시면 알려주세요. 즉시 반영하겠습니다.
```

응답이 없다는 이유로 자동 후속 메시지를 보내지 않는다. 별도 반복 안내 동의가 있을 때만 한 번
추가 안내할 수 있다.

## 3. 행동 소재 링크

이해도 게이트를 통과해 사람 검수까지 끝난 자산만 `/go/{creative_id}`로 배포한다.

```text
https://bideasy.kr/go/<승인 또는 게시 상태의 creative_id>
```

관리자 brief에 다음 값을 저장하고 리디렉션 API가 쿼리를 붙이게 한다.

| 필드 | 예시 |
|---|---|
| `utm_source` | 실제 채널명 또는 `naver` |
| `utm_medium` | `community`, `organic_video`, `cpc` |
| `utm_campaign` | `message_action_202608` |
| `variant` / `utm_content` | `A` 또는 `B` |
| `creative_id` | CreativeBrief UUID |

URL에 참가자 ID, 업체명, 전화번호, 이메일을 넣지 않는다. 임의 외부 URL로 직접 리디렉션하지 않는다.

## 4. 게시 전 체크리스트

- [ ] 운영진 또는 수신자의 사전 허가가 확인됐다.
- [ ] 채널 전용 접근 키 또는 승인된 `creative_id`를 쓴다.
- [ ] 조달청·나라장터 공식/제휴처럼 보이는 표현이 없다.
- [ ] 성과·시간 절감·자격 판정을 보장하지 않는다.
- [ ] 설치·활성화·후기를 보상 조건으로 두지 않는다.
- [ ] 실제 화면의 계정·회사·개인정보가 가려졌다.
- [ ] 같은 채널에 반복 게시하지 않는다.
- [ ] 철회·삭제 요청을 처리할 담당자와 경로가 명확하다.
