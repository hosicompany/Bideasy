BidEasy 개인정보처리방침

최종 업데이트일: 2026-11-04 시행일: 2026-11-11 (2026-11-02 공지분은 2026-11-09 시행) 이전 버전: 2026-10-23

호시(HOSI, 이하 “회사”)는 BidEasy Chrome 확장 프로그램과 웹사이트(bideasy.kr)(이하 “서비스”)를 통해 사용자의 개인정보를 보호하기 위해 다음과 같은 방침을 수립합니다.

또한 BidEasy 웹사이트(bideasy.kr)는 이용 통계를 위해 Google Analytics 4를, 무료 운영을 위한 광고 게재에 Google 애드센스와 카카오 애드핏을 사용하며, 이에 관한 사항은 4-1·4-2·4-4에서 안내합니다.

1. 개요

BidEasy 는 대한민국 공공조달 전자입찰 시스템(나라장터 G2B)에서의 입찰 분석·계산을 돕는 Chrome 확장 프로그램입니다. 본 정책은 본 확장 프로그램이 수집·이용하는 정보의 종류와 사용 목적, 보관 기간, 그리고 사용자의 권리에 관한 사항을 안내합니다.

본 확장은 사용자가 명시적으로 동의한 범위 내에서만 정보를 수집하며, 어떠한 목적으로도 제3자에게 정보를 판매하지 않습니다.

2. 수집하는 정보

본 확장 프로그램은 다음 정보를 수집할 수 있습니다.

2-1. 계정 정보 (회원 가입 시)

  • 이메일 주소
  • 이름 또는 닉네임
  • 비밀번호 (단방향 해시로 저장, 평문 보관 X)
  • (선택) 소셜 로그인 시: 카카오·네이버 소셜 ID, 프로필 이미지 URL
  • 체험(Trial) 시작·만료 시점 (신규 가입 시 자동 14일 Pro 체험 부여 — 재체험 방지 목적)

2-2. 서비스 이용 정보

  • 사용자가 분석한 입찰 공고의 식별번호 (bid_no) 및 분석 시점
  • AI 분석 결과 캐시 (LLM 비용 절감 목적)
  • 입찰가 계산 입력값 (기초금액, 사정률 등 — 사용자가 직접 입력)

2-3. 결제 정보 (Pro·Pro+ 구독 시)

  • 결제는 페이플(Payple)이 처리하며(일부 이전 결제는 토스페이먼츠), 회사는 신용카드 번호·CVC 등을 직접 보관하지 않습니다.
  • 결제대행사가 발급한 결제 식별자(주문번호 등)와 정기결제용 빌링키만 보관하며, 빌링키는 암호화해 저장합니다.

2-4. 기술적 정보

  • 확장 프로그램이 동작하는 도메인 (G2B, bideasy.kr) 의 페이지 URL 일부 (공고번호 추출 목적)
  • API 요청·응답 로그 (장애 진단 및 통계 목적)

2-5. 웹사이트에서 직접 입력하는 정보

  • 무료 자격 진단: 업종, 보유 면허, 사업장 지역, 시공능력평가액(선택), 결과를 받기 위해 남긴 이메일 또는 전화번호, 유입 경로(UTM 값)
  • 광고성 정보 수신 동의 기록: 동의·철회 시각, 동의 문구 버전, IP 주소, 브라우저 정보 (정보통신망법상 동의 사실 증명 목적)
  • 고객 문의: 챗봇 대화 내용, 문의 접수 시 남긴 회신용 이메일

2-6. 수집하지 않는 정보

  • 카드 정보, 금융계좌 정보
  • 사용자가 BidEasy 외부에서 방문한 다른 웹사이트 정보
  • 음성·영상·위치 정보
  • 사용자 디바이스의 파일·연락처

3. 사용 목적

수집된 정보는 다음 목적으로만 사용됩니다.

  1. 서비스 제공: 입찰가 계산, AI 공고 분석, 자격 매칭, 마감 알림 등 핵심 기능
  2. 계정 관리: 회원 가입·로그인·구독 등급 관리
  3. 결제 처리: 유료 구독료 결제·환불
  4. 알고리즘 개선: 익명화된 사용 데이터를 자가보정 알고리즘 학습에 활용 (개인 식별 불가능한 형태)
  5. 공지·문의 응대: 서비스 변경 안내, 사용자 문의 답변
  6. 법령 준수: 관련 법령에 따른 의무 이행
  7. 광고성 정보 발송: 수신에 동의하고 이메일 확인 절차를 마친 경우에만 발송하며, 언제든 수신을 거부할 수 있습니다

회사는 위 목적 외의 용도로 정보를 사용하지 않습니다.

BidEasy 는 다음 외부 서비스에 일부 정보를 전송합니다. 각 서비스의 정책을 함께 확인해주세요.

회사는 본 외부 서비스 외에 어떠한 제3자에게도 사용자 정보를 제공하지 않습니다.

4-1. 웹사이트 이용 통계 (Google Analytics 4)

BidEasy 웹사이트(bideasy.kr)는 서비스 이용 통계를 위해 Google LLC 가 제공하는 Google Analytics 4(이하 “GA4”)를 사용합니다.

  • 수집 항목
    • 방문한 페이지 주소·제목, 유입 경로
    • 이벤트: 버튼 클릭, 계산기 사용(calculate) 등. 계산기 이벤트에는 계약 유형, 결과 등급, 기초금액 구간, A값 입력 여부 같은 범주값만 포함됩니다.
    • 기기·브라우저 정보 (기기 유형, 운영체제, 브라우저, 화면 크기, 언어)
    • 대략적인 지역 (국가·도시 수준)
    • 쿠키 식별자 (_ga 등 GA4 쿠키에 저장되는 무작위 식별값)
  • 보내지 않는 정보: 계산기에 입력한 기초금액·A값·투찰률의 실제 값, 공고번호, 이메일·전화번호 등 직접 입력한 정보는 GA4 로 전송하지 않습니다.
  • 이용 목적: 서비스 이용 통계 분석 및 서비스 개선
  • 처리 위탁 및 국외 이전
    • 이전받는 자: Google LLC (연락처: https://support.google.com/policies)
    • 이전 국가: 미국
    • 이전 일시 및 방법: 웹사이트 방문·이용 시 사용자의 브라우저에서 Google 서버로 정보통신망을 통해 전송
    • 이전 항목: 위 수집 항목
    • 이용 목적: 웹사이트 이용 통계 분석
  • 보관 기간: Google Analytics 데이터 보관 설정에 따름
  • 거부 방법
    • 브라우저 설정에서 쿠키 저장을 차단할 수 있습니다.
    • Google Analytics 차단 부가기능(https://tools.google.com/dlpage/gaoptout)을 설치해 수집을 거부할 수 있습니다.
    • 거부하더라도 웹사이트 이용에는 제한이 없습니다.
  • Google 의 처리 방식은 Google 개인정보처리방침(https://policies.google.com/privacy)에서 확인하실 수 있습니다.

4-2. 웹사이트 광고 (Google 애드센스)

BidEasy 웹사이트(bideasy.kr)는 계산기 등 서비스를 무료로 운영하기 위해 Google LLC 가 제공하는 Google 애드센스 광고를 게재할 수 있습니다. Chrome 확장 프로그램에는 광고를 게재하지 않습니다.

  • 광고 쿠키 사용
    • Google 을 포함한 제3자 광고 사업자는 쿠키를 사용해, 사용자가 이 웹사이트 또는 다른 웹사이트를 이전에 방문한 기록을 바탕으로 광고를 게재합니다.
    • Google 은 광고 쿠키를 사용해, Google 과 파트너가 이 웹사이트 및 인터넷의 다른 웹사이트 방문 기록을 바탕으로 사용자에게 맞는 광고를 게재할 수 있도록 합니다.
  • 수집 항목: 광고 쿠키 식별자, 방문한 페이지 주소, 기기·브라우저 정보, IP 주소 기반의 대략적인 지역, 광고 노출·클릭 기록
  • 보내지 않는 정보: 회사는 광고 게재를 위해 계산기에 입력한 금액, 공고번호, 이메일·전화번호 등 사용자가 직접 입력한 정보를 Google 에 제공하지 않습니다.
  • 이용 목적: 광고 게재, 광고 성과 측정, 부정 클릭 방지
  • 처리 위탁 및 국외 이전
    • 이전받는 자: Google LLC (연락처: https://support.google.com/policies)
    • 이전 국가: 미국
    • 이전 일시 및 방법: 웹사이트 방문·이용 시 사용자의 브라우저에서 Google 서버로 정보통신망을 통해 전송
    • 이전 항목: 위 수집 항목
    • 이용 목적: 위 이용 목적과 같음
  • 보관 기간: Google 의 광고 데이터 보관 정책에 따름
  • 맞춤 광고 거부 방법
    • Google 광고 설정(https://adssettings.google.com)에서 맞춤 광고를 끌 수 있습니다.
    • www.aboutads.info 에서 다른 제3자 광고 사업자의 맞춤 광고 쿠키를 거부할 수 있습니다.
    • 브라우저 설정에서 쿠키 저장을 차단할 수 있습니다.
    • 거부하더라도 웹사이트 이용에는 제한이 없으며, 맞춤형이 아닌 일반 광고는 계속 표시될 수 있습니다.
  • Google 이 광고에서 정보를 사용하는 방식은 https://policies.google.com/technologies/partner-sites 에서 확인하실 수 있습니다.

4-3. AI 분석·챗봇 (OpenRouter)

AI 공고 분석과 챗봇 답변은 OpenRouter, Inc. 를 통해 AI 모델 제공사(OpenAI, Anthropic 등)의 모델로 처리합니다.

  • 전송 정보: 공고 제목·본문 텍스트, 챗봇에 입력한 문의 내용.
  • 처리 위탁 및 국외 이전
    • 이전받는 자: OpenRouter, Inc. (연락처: https://openrouter.ai)
    • 이전 국가: 미국
    • 이전 일시 및 방법: AI 분석 요청·챗봇 질문 시 회사 서버에서 정보통신망을 통해 전송
    • 이전 항목: 위 전송 정보
    • 이용 목적: AI 공고 요약·분석, 챗봇 답변 생성
  • 보관 기간: OpenRouter 및 모델 제공사의 데이터 보관 정책에 따름

4-4. 웹사이트 광고 (카카오 애드핏)

BidEasy 웹사이트(bideasy.kr)는 계산기 등 서비스를 무료로 운영하기 위해 주식회사 카카오가 제공하는 카카오 애드핏 광고를 게재할 수 있습니다. Chrome 확장 프로그램에는 광고를 게재하지 않습니다.

  • 행태정보 수집을 허용하는 사업자: 주식회사 카카오
  • 수집 항목: 광고 쿠키 식별자, 방문한 페이지 주소, 기기·브라우저 정보, 광고 노출·클릭 기록
  • 수집 방법: 사용자가 웹사이트를 방문하면 사용자의 브라우저에서 카카오가 자동으로 수집합니다.
  • 보내지 않는 정보: 회사는 광고 게재를 위해 계산기에 입력한 금액, 공고번호, 이메일·전화번호 등 사용자가 직접 입력한 정보를 카카오에 제공하지 않습니다.
  • 이용 목적: 광고 게재, 사용자 관심에 맞는 광고 제공, 광고 성과 측정, 부정 클릭 방지
  • 보관 기간: 카카오의 광고 데이터 보관 정책에 따름
  • 국외 이전: 없음 (국내 사업자)
  • 맞춤형 광고 거부 방법
    • 브라우저 설정에서 쿠키 저장을 차단할 수 있습니다.
    • 카카오의 맞춤형 광고 안내 페이지 또는 카카오계정 설정에서 맞춤형 광고를 거부할 수 있습니다.
    • 거부하더라도 웹사이트 이용에는 제한이 없으며, 맞춤형이 아닌 일반 광고는 계속 표시될 수 있습니다.
  • 카카오의 개인정보 처리 방식은 카카오 개인정보처리방침(https://www.kakao.com/policy/privacy)에서 확인하실 수 있습니다.

5. 보관 기간 및 파기

5-1. 보관 기간

  • 계정 정보: 회원 탈퇴 시까지 (탈퇴 즉시 파기)
  • 이용 기록·캐시: 최대 3년 (서비스 품질 분석 후 파기)
  • 결제 기록: 관련 법령에 따라 5년 (전자상거래법)
  • 로그 기록: 최대 1년
  • 자격 진단 연락처: 수신 거부 또는 삭제 요청 시까지
  • 수신 동의·철회 기록: 동의 사실을 증명하기 위해 회원 탈퇴·삭제 요청 이후에도 보관할 수 있습니다

5-2. 파기 절차

  • 사용자가 탈퇴 요청 시 즉시 개인정보를 삭제합니다.
  • 법령상 보관 의무가 있는 정보는 해당 기간 종료 후 즉시 파기됩니다.
  • 파기 방법: 전자적 파일은 복구·재생할 수 없는 방법으로 영구 삭제.

6. 사용자 권리

사용자는 다음 권리를 행사할 수 있습니다.

  1. 열람·정정: 본인 정보 조회 및 수정 (BidEasy 앱·웹 마이페이지)
  2. 삭제·탈퇴: 계정 탈퇴 요청 시 즉시 처리
  3. 처리 정지: 개인정보 처리 정지 요청
  4. 데이터 이동: 본인 정보 사본 요청

권리 행사는 아래 연락처로 요청하실 수 있으며, 회사는 영업일 기준 7일 이내 처리합니다.

7. 보안 조치

회사는 사용자 정보 보호를 위해 다음 조치를 시행합니다.

  • 암호화: 모든 API 통신은 HTTPS (TLS 1.2+)로 암호화
  • 인증: JWT 기반 토큰 인증 (만료 자동 처리)
  • 접근 제어: 운영자도 권한 있는 사용자만 데이터 접근 가능 (최소 권한 원칙)
  • 비밀번호 해싱: bcrypt 단방향 해시 저장 (원본 비밀번호 복구 불가)
  • 인프라: AWS Lightsail (한국 서울 리전) + Let’s Encrypt SSL
  • 모니터링: 비정상 접근 시도 감지 및 차단 (fail2ban)

8. 확장 프로그램 권한 사용 사유

Chrome 확장 프로그램이 요청하는 각 권한의 사용 목적은 다음과 같습니다.

권한 사용 목적
storage 사용자 설정·로그인 토큰 로컬 저장
sidePanel 사이드패널 UI 제공 (분석·계산 화면)
activeTab 현재 사용자가 보고 있는 공고 페이지의 식별번호 추출
alarms 마감 임박 공고 정기 체크
notifications 마감 알림 푸시 표시
scripting 나라장터 페이지에 분석 결과 오버레이 표시
host_permissions: g2b.go.kr 나라장터 페이지에서 공고 정보 자동 추출
host_permissions: bideasy.kr, api.bideasy.kr BidEasy 백엔드 API 호출 (분석·계산·인증)

위 권한은 모두 명시된 목적 외에는 사용되지 않습니다.
