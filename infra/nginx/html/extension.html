BidEasy 크롬 확장 프로그램

나라장터(g2b.go.kr) 공고 페이지를 열어 둔 채로, 화면 옆 사이드패널에서 투찰가와 낙찰하한선을 바로 계산할 수 있어요. 공고 보던 탭에서 계산기 탭으로 옮겨 가서 공고번호를 다시 입력하는 수고를 줄여 줍니다. 가입 없이 바로 설치해서 써 볼 수 있고, 보고 있는 공고를 알아서 인식해 계산에 필요한 숫자를 채워요.

Chrome 웹스토어에서 설치

무엇을 하나요

나라장터에서 공고를 여러 건 살펴보다 보면, 괜찮아 보이는 공고를 발견할 때마다 공고번호를 적어 두고 다른 탭의 계산기로 옮겨 가는 일이 반복됩니다. 확장은 이 과정을 줄이려고 만들었어요. 공고 페이지를 보던 그 자리에서 사이드패널을 열면 바로 계산 결과가 나옵니다. 기능은 로그인 여부와 관계없이 쓸 수 있는 것과, 기존 회원 계정이 있어야 쓸 수 있는 것으로 나뉘어 있어요. BidEasy는 지금 유료 요금제와 신규 회원가입을 잠시 쉬고 있어서, 계정이 필요한 기능은 기존 회원만 이용할 수 있습니다.

로그인 없이 바로 되는 것

  • 보고 있는 나라장터 공고를 사이드패널이 자동으로 인식해, 투찰가·낙찰하한선을 계산해요. 공식은 웹 투찰가 계산기와 같아요 — 투찰가 = (기초금액 − A값) × 투찰률 + A값(10원 미만 절사), 하한선은 같은 공식에 낙찰하한율을 넣어 계산해요. A값이 공개된 공고는 A값도 자동으로 반영돼요.
  • 기초금액이 아직 공개되지 않은 공고는 추정치를 만들지 않고 '미확인'으로 표시해요. 추정가격을 대신 넣으면 하한선이 실제보다 약 9% 낮게 나와, 안전하다고 잘못 판단할 수 있기 때문이에요.
  • 공고에 하한율이 적혀 있으면 그 값을 그대로 쓰고, 없으면 현행 금액대별 기준을 적용해요. 금액대별 기준은 낙찰하한율표에서도 볼 수 있어요.
  • 사이드패널의 '무료 조건 진단' 버튼으로 웹의 무료 조건 진단 페이지를 바로 열 수 있어요. 업종·지역을 넣으면 참가 가능성이 있는 공고 후보를 확인할 수 있어요.

계정이 필요한 것 (기존 회원 대상, 신규 가입 잠시 중단)

  • 공고 AI 요약, 독소조항 같은 주의 조항 표시 — 공고 본문에서 눈에 잘 안 들어올 수 있는 조건을 짚어 줘요.
  • 내 자격 조건과 공고 요건 대조 — 미리 등록해 둔 업종·지역 같은 정보로 참가 가능 여부를 함께 보여줘요.
  • 관심 공고 마감 알림 — 등록해 둔 공고의 마감이 다가오면 알려줘요.

계정이 필요한 기능은 웹(bideasy.kr)과 같은 계정을 그대로 씁니다. bideasy.kr에서 로그인하면 확장에도 같은 계정이 연결돼요.

설치하고 쓰는 순서

  1. 위 버튼으로 크롬 웹스토어에서 BidEasy 확장을 설치해요.
  2. 나라장터(www.g2b.go.kr)에서 확인하고 싶은 공고의 상세 페이지를 열어요. 목록 화면이 아니라 공고 상세 화면을 열어야 해요.
  3. 브라우저 오른쪽 위 BidEasy 아이콘을 눌러요.
  4. 사이드패널이 열리면서 그 공고의 기초금액·A값(공개된 경우)을 가져와 계산 결과를 보여줘요.
  5. 투찰률을 조정하며 투찰가와 낙찰하한선을 확인해요. 다른 공고 페이지로 넘어가면 사이드패널 내용도 그 공고 기준으로 바뀌어요.

요청하는 권한과 이유

권한쓰는 곳
storage설정값 저장
sidePanel사이드패널 화면 표시
activeTab지금 보고 있는 탭의 공고 정보 읽기
alarms, notifications관심 공고 마감 알림
scripting공고 페이지에서 정보 읽어오기
g2b.go.kr 접속나라장터 공고 페이지 읽기
bideasy.kr, api.bideasy.kr 접속계산 기준 조회, 로그인 연동

storage는 로그인 상태와 설정값을 브라우저에 저장하는 데 쓰고, sidePanel은 공고 페이지 옆에 계산 화면을 띄우기 위한 크롬의 사이드패널 기능이에요. activeTab과 scripting은 지금 보고 있는 공고 페이지에서 공고번호 같은 정보를 읽어 오는 데 쓰고, alarms·notifications는 관심 공고로 등록한 공고의 마감을 알려 주는 데 씁니다(계정 필요 기능). 접속 범위를 g2b.go.kr과 bideasy.kr·api.bideasy.kr로 한정한 것도 같은 이유예요 — 공고를 읽어 오고 계산 기준을 조회하는 데 필요한 범위만 열어 두고, 그 밖의 사이트에 대한 상시 접근 권한은 요청하지 않아요.

로그인한 상태에서 사이드패널로 공고를 확인하면, 공개된 공고번호와 확인 시각을 서비스 개선 측정용으로 저장해요. 방문 중인 페이지의 URL이나 공고명, 회사 프로필은 이 계측에 보내지 않아요. 자세한 내용은 개인정보처리방침에서 확인하세요.

웹만으로도 되는 것과 비교

계산기만 쓰려면 확장을 설치하지 않고 웹에서 바로 공고번호나 숫자를 입력해도 됩니다. 확장은 나라장터 공고를 자주, 여러 건씩 훑어보는 분들을 위한 보조 도구예요.

기능웹(bideasy.kr)확장
투찰가·하한선 계산공고번호 입력 또는 직접 입력보고 있는 공고를 자동 인식
무료 조건 진단가능가능(사이드패널에서 바로 연결)
AI 요약·주의 조항, 자격 대조, 마감 알림계정 필요(신규 가입 중단)계정 필요(신규 가입 중단)

계산 자체는 웹 계산기만으로도 할 수 있어요. 확장은 나라장터 공고 페이지를 떠나지 않고, 공고번호를 다시 입력할 필요 없이 같은 계산을 바로 볼 수 있다는 점이 다릅니다. 공고를 여러 건 훑어보며 빠르게 확인할 때 특히 유용해요.

하지 않는 것

  • 낙찰가를 예측하지 않습니다. 예정가격은 입찰자들이 고른 복수예비가격 가운데 많이 선택된 값들의 평균으로 개찰 때 정해지는 값이라, 투찰 전에는 미리 알 수 없어요.
  • 낙찰 가능성이나 순위를 계산하지 않습니다.
  • 계산 결과로 낙찰을 보장하지 않습니다. 사이드패널이 보여주는 건 공고 당시 확인된 숫자를 바탕으로 한 계산값일 뿐이에요.
  • 나라장터의 공식 서비스가 아닙니다. 조달청·나라장터와 제휴 관계도 아니고, 운영 주체는 민간 업체 호시(HOSI)예요.
  • 투찰을 대신 하지 않습니다. 실제 투찰 제출은 나라장터 화면에서 직접 진행해 주세요.

문제가 생기면

사이드패널이 뜨지 않으면 먼저 공고 페이지를 새로고침해 보세요. 나라장터 공고 상세 화면이 아닌 목록 화면이나 다른 페이지에서는 계산 대상 공고를 찾지 못할 수 있어요. 다른 탭에서 열어 둔 BidEasy 사이드패널이 그대로 남아 있는 경우도 있으니, 지금 보고 있는 탭이 맞는지도 확인해 보세요. 그래도 해결되지 않으면 문의하기로 알려 주세요.
