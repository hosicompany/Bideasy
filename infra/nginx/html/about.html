BidEasy 소개

BidEasy는 나라장터(조달청 전자조달시스템) 입찰에 참여하는 중소 시공사가 투찰 전에 숫자를 한 번 더 확인할 수 있도록 만든 무료 계산기 사이트입니다. 가입이나 로그인 없이 쓸 수 있어요.

무엇을 할 수 있나요

  • 투찰가 계산기 — 기초금액·투찰률·A값을 넣으면 투찰가와 낙찰하한선을 1원 단위로 계산해요.
  • 낙찰하한율표 — 공사 금액대별 낙찰하한율을 한 표로 정리했어요.
  • A값 참고값 — 실제 공고에 공개된 A값을 금액대별로 모아 보여드려요.
  • 공고 검색 — 나라장터 공고를 찾아 계산기로 바로 불러올 수 있어요.
  • 블로그 — 기초금액·예정가격·사정률 같은 입찰 기초 개념을 쉽게 풀어 써요.

하지 않는 것

  • 낙찰가를 예측하지 않습니다. 예정가격은 복수예비가격 추첨으로 정해지는 값이라 미리 알 수 없어요.
  • 낙찰 가능성이나 순위를 계산하지 않습니다.
  • 계산 결과로 낙찰을 보장하지 않습니다. 최종 투찰 금액은 공고문과 나라장터 화면에서 직접 확인해 주세요.

데이터 출처

  • 공고·기초금액·개찰 결과는 공공데이터포털(data.go.kr)이 제공하는 조달청 나라장터 OpenAPI에서 가져와요.
  • 낙찰하한율은 공고에 적힌 값을 먼저 쓰고, 없으면 현행 기준표의 추정가격 금액대를 적용해요.
  • 틀린 숫자를 발견하시면 문의하기로 알려 주세요. 확인 후 바로 고칩니다.

운영 방식

BidEasy는 무료로 운영되며, 운영비 마련을 위해 사이트에 광고를 게재할 수 있습니다. 광고와 개인정보 처리 방식은 개인정보처리방침에서 안내해요. BidEasy는 조달청·나라장터의 공식 또는 제휴 서비스가 아닌 민간 서비스입니다.
